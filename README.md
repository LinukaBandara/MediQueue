# MediQueue

MediQueue is a healthcare queue and appointment workflow platform designed to make clinic visits easier to manage for patients, staff, and healthcare providers.

## Stack
- Next.js frontend
- Laravel backend
- Relational database
- Laravel Echo / Reverb for real-time communication

## Core workflow
- Patient and clinic workflows
- Queue and appointment management
- Live queue status updates
- Notifications for upcoming turns
- Authenticated staff operations
- Real-time frontend/backend communication

## Repository structure
mediqueue-frontend/   Next.js application
mediqueue-backend/    Laravel backend

## Development
Run the frontend and backend from their respective directories using the commands documented in each application.

Keep environment files and service credentials outside source control. Use the provided environment examples for local configuration.
